Using Perks

Where to find perks, how to use them, and what to check if one does not work as expected.

Where to find perks

You may find perks directly on the current GRAM or inside My Collection. Where they appear depends on the perk type and how that GRAM is configured.

How to use a perk

  1. Open the GRAM or collection area where the perk appears.
  2. Review the action shown for that perk.
  3. Follow the displayed redemption or usage step.

Different kinds of perks

Some perks are digital. Others may be linked to a partner, location, or real-world experience.

If a perk does not work

  • Check that you are using the correct account.
  • Check whether the perk appears on the current GRAM or in your collection.
  • Refresh the page if the state looks outdated.
Important: Availability can depend on the current GRAM, account state, or the perk's own status.
